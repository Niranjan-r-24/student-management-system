# 🎓 Student Management System

A beginner-friendly Student Management System built using FastAPI and Streamlit.

## Features

- Add Student
- View Students
- Search Student
- Update Student
- Delete Student

## Technologies Used

- Python
- FastAPI
- Streamlit
- JSON

## Installation

```bash
pip install -r requirements.txt
```

Run Backend

```bash
uvicorn main:app --reload
```

Run Frontend

```bash
streamlit run app.py
```
